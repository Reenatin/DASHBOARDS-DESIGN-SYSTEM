# Segurança e publicação

Este projeto contém apenas exemplos sintéticos e código visual. Não publicar credenciais,
identificadores de ambientes, URLs privadas, chaves de APIs, ativos de clientes ou fontes licenciadas.

**Ponto de liberação:** os arquivos derivados do repositório YDUQS v1.0.0 foram preparados
para revisão LOCAL. A redistribuição em GitHub público depende de autorização do titular
ou análise de licenciamento aplicável, mesmo após remover dados pessoais e segredos.
Nenhuma autorização é presumida por este repositório.
