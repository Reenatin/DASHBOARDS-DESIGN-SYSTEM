# Gráfico de linha — Transferências ao Humano

**Objetivo:** reutilizar no mesmo TSX a visualização de transferências ao humano da
Visão Geral da YDUQS v1.0.0, sem redesenho a cada dashboard.

**Entregue localmente:** variantes URA e IAM no mesmo seletor; linha, marcadores,
gradiente, tooltip estilizado, guia vertical, foco, temas claro/escuro e estados de
carregamento/erro/sem dados. Dados sintéticos apenas no projeto de demonstração.

**Componentes:** `componentes/grafico-linha-transferencias/GraficoLinhaTransferencias.tsx`
e `grafico-linha-transferencias.css`.

**Prévia:** `src/App.tsx` carrega o componente original com `mock/transferencias.ts`.

**Origem:** YDUQS v1.0.0, SHA `debdaeff078cc457651a8748a52d6d4eaefb4f51`.
